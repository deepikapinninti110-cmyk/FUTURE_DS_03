📊 Task 3: College Event Feedback Analysis 📌 Overview

This project analyzes college event feedback to understand student satisfaction and event performance using Power BI. The goal is to convert raw feedback data into meaningful visual insights.

📂 Dataset

Includes student feedback with:

Event name and type

Ratings

Feedback text

Sentiment (Positive, Neutral, Negative)

📈 Dashboard Insights

The Power BI dashboard contains:

Sentiment distribution of feedback

Feedback count by event type

Total ratings by event

Detailed feedback table with filters

🛠 Tools Used

Power BI Desktop, Excel
